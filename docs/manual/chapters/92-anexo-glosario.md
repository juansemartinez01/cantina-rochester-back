## Anexo C. Glosario

| Término | Significado |
| --- | --- |
| Almacen | Sucursal o punto de venta. Cada almacén tiene su propio stock, caja y precios. |
| Caja | Sesión de trabajo con dinero. Se abre al empezar el turno y se cierra al terminar, con arqueo. |
| Movimiento stock | Cualquier entrada o salida de mercadería del depósito. |
| Cuenta corriente | Crédito otorgado a un cliente para que compre ahora y pague después. |
| Parametro reorden | Stock mínimo a partir del cual el sistema avisa que hay que reponer. |
| Orden compra | Pedido de mercadería a un proveedor. |
| Extraccion | Retiro de dinero de la caja. |
| Promocion | Combo o descuento aplicable a una venta. |
| Ucc | Universidad Católica de Córdoba. Como medio de pago identifica las ventas que quedan a cuenta de la universidad, para clientes que compran mediante cuenta corriente. |
